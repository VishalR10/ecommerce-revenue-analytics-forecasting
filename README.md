# E-Commerce Revenue Analytics & Forecasting

## Project Overview
This project analyzes e-commerce sales performance using Python, SQL, and Power BI. The goal was to identify revenue trends, profitability drivers, regional performance, and top-performing products while building an executive-style interactive dashboard.

---

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- SQL (MySQL)
- Power BI
- Git & GitHub

---

## Key Business Insights
- Technology category generated the highest profit.
- Revenue showed strong growth trends toward year-end periods.
- Certain products generated high revenue but low profitability.
- Regional analysis highlighted significant sales concentration in specific regions.

## Project Workflow

### 1. Data Cleaning & Preparation
- Removed missing values

- Revenue by category
- Profit by category
- Top-performing products
- Loss-making products
- Monthly revenue analysis

### 3. Power BI Dashboard
- KPI cards
- Monthly revenue trend
- Regional analysis
- Category profitability
- Product-level insights

## Forecasting Objective
The project prepares the foundation for future revenue forecasting and business performance prediction using time-series analysis techniques.
